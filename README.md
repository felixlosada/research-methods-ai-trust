# Does AI Change Candidate Trust?

The project was developed for **Research Methods for International Relations at IE University**. It uses 70 questionnaire responses and eight regression models. This repository accompanies our research poster and provides supporting analysis, tables, and additional figures.

Our main hypothesis was that AI advertisements would receive lower candidate-trust ratings than non-AI advertisements.

The analysis includes **70 responses**. Candidate trust was measured on a **1–10 scale**.
